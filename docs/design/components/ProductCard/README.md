# ProductCard

Card di un prodotto o di una box dello shop: foto quadrata, produttore, nome, prezzo, aggiunta al carrello. Variante orizzontale `is-product--row` per le pagine di luogo e attività.

- **Produttore sempre visibile**, in maiuscolo `pistacchio`: è il motivo per comprare da noi.
- **Prezzo** IVA inclusa, in Fraunces. Spedizione nel carrello, non nella card.
- Aggiunta al carrello con bottone secondario: nello shop la pagina non ha un'azione principale per prodotto.
- Nelle schede di attività e luogo, al massimo tre prodotti in variante orizzontale, dopo le attività vicine.
- Prodotti deperibili: nel carrello avviso sulla spedizione nei mesi caldi.
