# Button

Il bottone per tutte le azioni: principale su `coccio`, secondario con bordo, testuale per azioni leggere.

- **Principale** (`is-btn--primary`): una sola per vista, contando anche l'intestazione. Se l'hero ha l'azione principale, quella dell'intestazione è secondaria finché l'hero è visibile.
- **Secondario** (`is-btn--secondary`): alternative, navigazione, offerte affiliate.
- **Testuale** (`is-btn--ghost`): azioni leggere dentro il contenuto, in `coccio-text`.
- **Piccolo** (`is-btn--sm`): 36px disegnati, 44px di area toccabile.
- Etichette con verbo e oggetto: "Aggiungi al viaggio", non "Clicca qui". Mai "Prenota tutto": vedi Schemi, Prenotazioni.
