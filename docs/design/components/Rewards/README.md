# Rewards

Pillola dei punti e timbri: le uniche superfici `zagara` del prodotto.

- **Pillola punti:** a riposo `zagara-tint` con bordo `zagara`, per non rubare attenzione all'azione principale. Diventa piena (`is-points--earned`) solo quando si guadagnano punti, per `dur-slow`, poi torna a riposo.
- **Timbro:** 120px, cerchio `zagara` con anello tratteggiato. Nome di al massimo 16 caratteri per riga: i nomi dei badge si scrivono per starci, non si spezzano con il trattino. Rotazione diversa per ogni timbro, tra -6° e 4°.
- **Bloccato:** `calce-sunk`, senza rotazione, con il progresso sotto il nome.
- **Appena sbloccato:** animazione di timbratura una volta sola.
- Le recensioni danno punti: ogni recensione mostra l'etichetta "Recensione con premio" (vedi Schemi).
